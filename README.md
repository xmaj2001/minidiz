# 📊 Church Finance & Management System

Sistema de **Gestão Financeira e Administrativa para Igrejas**, projetado para oferecer **transparência, organização e controle total** das atividades financeiras e operacionais de cada paróquia.

A plataforma permite que a igreja central gerencie múltiplas paróquias espalhadas pelo país (ou mundo), controlando desde o **registro de membros**, **administração de grupos**, **contribuições (dízimos, ofertas, doações em dinheiro ou bens)**, até a **gestão de fundos internos, despesas, eventos e relatórios financeiros detalhados**.

---

## 🚀 Tecnologias Principais

| Tech | Uso |
|------|-----|
| **Node.js / NestJS** | Backend |
| **Prisma ORM** | Modelagem de dados |
| **PostgreSQL** | Banco de dados |
| **JWT (Access + Refresh Token)** | Autenticação |
| **OAuth Providers** | Login Social (Google, Facebook, etc.) |

---

## 🔥 Funcionalidades Principais

### 🏛 Gestão Eclesiástica
- Estrutura hierárquica (Igreja Central → Paróquias → Grupos)
- Cadastro e acompanhamento de membros  
- Histórico de **migração entre paróquias**
- Classificação por estado religioso (batizado, confirmado etc.)

### 💰 Gestão Financeira
- Controle de **contribuições (dízimo, oferta, doações)**
- Suporte a pagamentos **em dinheiro ou bens**
- Fundos próprios por **paróquia e grupo**
- Controle de **despesas, custos e eventos**
- Dashboard financeiro em tempo real

### 🔐 Autenticação e Segurança
- Login por **email/senha** ou **providers externos**
- JWT com **Access + Refresh Token**
- Controle de **sessões por dispositivo**
- Logout individual ou geral
- **Sistema de logs/auditoria**
